# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/KalkidanAB-22/portfolio.git
```

## Navigate into the project

```bash
cd portfolio
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

The application will run locally at:

```
http://localhost:5173
```
